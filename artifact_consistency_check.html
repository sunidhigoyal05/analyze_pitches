A methodology check for The Appeal Arc

Coded Twice

The rubric/appeal labels throughout this project come from an LLM reading each transcript window and making a judgment call — not a fixed algorithm. So: if you coded the same pitch twice, would you get the same answer? Stick 'Em's 10-window pitch was coded a second time, completely independently (a fresh read, blind to the original labels), to find out.

Takeaway

Both disagreements happened on the two lowest-confidence windows in the original coding (0.50 and 0.70) — exactly what the confidence score is supposed to flag. Every window scored 0.75 or higher came back identical on the rerun. This is one pitch, one rerun — not a rigorous statistical study — but it's a real, honest first data point on how much to trust any single window's label versus the aggregate patterns (Logos dominating across dozens of windows, LinkedIn's zero-Pathos deck) that this project's actual findings rest on.
